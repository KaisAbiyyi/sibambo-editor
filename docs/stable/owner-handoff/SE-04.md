## A. Preflight dan pengujian tanpa kredensial

1. **Buka** Windows Terminal → PowerShell. **Ekspektasi:** terminal PowerShell terbuka. **Bila gagal:** buka PowerShell melalui Start Menu.
2. **Pindah** ke folder repo Editor (biasanya D:\projects\sibambo\sibambo-editor). **Ekspektasi:** ada folder apps/editor dan file package.json. **Bila gagal:** cari folder Git clone yang benar; jangan clone repo publik lain.
3. **Jalankan** script preflight dari root repo:

~~~powershell
powershell -ExecutionPolicy Bypass -File .\scripts\owner_acceptance\se04.ps1
~~~

   **Ekspektasi:** menampilkan versi Git/Bun, branch, exact HEAD, working tree, daftar file SE-04. Tidak meminta token atau membuat perubahan. **Bila gagal:** catat error dan jangan reset/hapus local edits.
4. **Periksa** branch benar-benar PR #22 dan git status bersih sebelum checkout/switch. **Ekspektasi:** HEAD commit dalam PR; working tree tidak berisi pekerjaan orang lain. **Bila gagal:** STOP, simpan pekerjaan yang belum di-commit.
5. **Jalankan** dari root repo, satu per satu:

~~~powershell
bun install --frozen-lockfile
bun run check
bun run build
bun test ./apps/editor/unit/mcp
~~~

   **Ekspektasi:** semua exit code 0. **Bila gagal:** lampirkan log disamarkan pada PR (tanpa secret), jangan ubah source.
6. **Jalankan** browser test:

~~~powershell
cd apps/editor
bun x playwright install chromium
bun x playwright test --config ./playwright.config.ts ./tests/mcp-onboarding.spec.ts
~~~

   **Ekspektasi:** mock browser suite PASS untuk identity spoof/CSRF/revoke/pause/keyboard dan lebar 320, 768, 1440. **Bila gagal:** laporkan test title dan output; jangan klaim real pairing PASS.
7. **Kembali** ke root repo dan mulai Editor:

~~~powershell
cd ../..
bun run dev
~~~

   **Ekspektasi:** alamat localhost 127.0.0.1:5175, tanpa koneksi tunnel/agent. **Bila gagal:** tutup proses yang memakai port 5175, ulangi tanpa menghapus data.
8. **Buka** http://127.0.0.1:5175/ pada browser desktop. **Ekspektasi:** UI Editor tampil seperti biasa. **Bila gagal:** pastikan bun run dev masih aktif.
9. **Pilih** Extensions → MCP Extension. **Ekspektasi:** panel in-app menampilkan status disconnected + penjelasan OIDC belum dikonfigurasi; bukan addon browser. **Bila gagal:** screenshot UI saja, tanpa token.
10. **Uji** Tab/Enter/Escape dan Responsive Mode pada 320/768/1440 px. **Ekspektasi:** kontrol terbaca, dapat difokuskan dan Escape menutup panel; reopen mempertahankan draft owner yang belum dikirim. **Bila gagal:** simpan width dan screenshot disamarkan.

## B. Konfigurasi aman oleh owner nonproduction (jangan membuat resource tanpa izin)

1. **Buka** https://manage.auth0.com/ dan pilih tenant nonproduction yang sudah disetujui. **Ekspektasi:** halaman tenant + Applications. **Bila belum ada:** STOP; jangan memakai tenant production.
2. **Pilih** Applications → Applications → Create Application → **Regular Web Application**. Ini aplikasi login owner untuk BFF (confidential), **bukan** client agent/SPA. **Ekspektasi:** tipe Regular Web Application. **Bila salah:** hentikan dan betulkan jenis aplikasi.
3. **Masukkan** Allowed Callback URLs exact: https://EDITOR-ORIGIN/api/mcp/callback (ganti EDITOR-ORIGIN dengan hostname Editor nonproduction yang benar). Allowed Web Origins dan Logout URLs hanya origin yang tepercaya. **Ekspektasi:** tidak ada wildcard. **Bila belum ada HTTPS origin:** STOP sebelum tes real.
4. **Identifikasi** Auth0 API/audience resmi untuk MCP backend SE-03. BFF owner dan setiap agent OAuth berbeda client; Claude Code dan Codex membutuhkan subject/client terpisah. **Ekspektasi:** audience, scopes dan issuer konsisten dengan backend. **Bila backend belum implement:** STOP pada tahap ini.
5. **Masukkan** env berikut melalui secret manager server Editor (bukan PUBLIC_, bukan git/.env yang di-commit): SE04_AUTH_ISSUER (nilai issuer HARUS exact sama dengan OIDC discovery dan JWT iss, termasuk slash terakhir), SE04_AUTH_CLIENT_ID, SE04_AUTH_CLIENT_SECRET, SE04_AUTH_AUDIENCE, SE04_SESSION_KEY, SE04_PUBLIC_ORIGIN, SE04_SERVICE_BASE_URL. SE04_SESSION_KEY harus 32 byte acak dalam base64url. **Ekspektasi:** nama variabel terlihat, nilai secret tertutup. **Bila format salah:** STOP, jangan kirim nilainya ke agent/chat.
6. **Pastikan** service SE-03 mengimplementasikan kontrak se04-owner-mcp-v1 (detail pada bagian E). Service wajib memverifikasi bearer issuer/audience/owner/project; pending agent OAuth; 8 karakter pair code, TTL 5 menit dan maksimal 5 percobaan; grant write explicit; pause/revoke segera; inbox. **Ekspektasi:** service memiliki bukti tes security. **Bila tidak:** real tes tetap NOT_RUN.
7. **Verifikasi** HTTPS/WSS tunnel nonproduction mengarah hanya ke port localhost service yang dimaksud; tidak mengekspos stdio atau LAN service lain. **Ekspektasi:** origin allowlist dan akses project berfungsi. **Bila gagal:** tutup tunnel; tidak boleh bypass auth.

## C. Langkah acceptance live (setelah semua B PASS)

1. **Buka** Editor HTTPS nonproduction di incognito dan panel MCP. **Ekspektasi:** disconnected, tanpa writer. **Bila gagal:** screenshot UI dan STOP.
2. **Klik** Masuk dengan OIDC, login owner melalui Auth0. **Ekspektasi:** kembali ke Editor dengan subject benar; tidak ada access token di localStorage atau URL. **Bila gagal:** simpan status kode HTTP saja; jangan menyalin authorization code/secret.
3. **Masukkan** ID proyek sintetis yang memang dimiliki owner. **Ekspektasi:** capability, writer dan angka revision berasal dari service; bukan nilai dummy. **Bila proyek lain terbuka:** STOP — isolasi owner gagal.
4. **Jalankan** pada terminal terpisah Claude Code yang terpasang resmi:

~~~powershell
claude mcp add --transport http sibambo https://MCP-HTTPS-ORIGIN/mcp
~~~

   **Ekspektasi:** server terdaftar; di Claude Code, menu /mcp memulai auth OAuth jika belum terhubung. **Bila CLI berbeda:** pakai claude mcp --help dan https://code.claude.com/docs/en/mcp.
5. **Lihat** request pending pada panel owner, baca clientId dan agentSubject asli (nama tampilan tidak tepercaya). Cocokkan 8 karakter yang disajikan client, lalu **Tolak** pairing pertama. **Ekspektasi:** tidak ada writer. **Bila write tetap bisa:** STOP.
6. **Ulangi** pairing dan coba salah kode, expired code dan maksimal percobaan. **Ekspektasi:** selalu ditolak; kode benar + OAuth subject dan grant owner yang cocok baru memberi read. **Bila salah kode lolos:** STOP.
7. **Setujui** read-only untuk proyek sintetis, lalu tes write tool. **Ekspektasi:** read boleh, write ditolak. **Bila write lolos:** STOP.
8. **Setujui** write hanya setelah benar-benar dibutuhkan, kemudian klik **Jeda semua perubahan** dan **Cabut akses**. **Ekspektasi:** server menolak mutation segera pada keadaan pause/revoke, bukan hanya tombol UI yang berubah. **Bila tidak:** STOP.
9. **Daftarkan** Codex sebagai client berbeda:

~~~powershell
codex mcp add sibambo --url https://MCP-HTTPS-ORIGIN/mcp
codex mcp login sibambo
~~~

   **Ekspektasi:** login OAuth Codex terpisah, clientId/agentSubject berbeda, tidak mewarisi grant Claude. **Bila CLI berbeda:** periksa codex mcp --help dan https://developers.openai.com/codex/mcp/.
10. **Kirim** Minta revisi ke agent: teks, optional module IDs, dan parameter angka (contoh width=3.5); uji open → read → addressed atau withdrawn. **Ekspektasi:** pesan masuk inbox tetapi tidak pernah mengotorisasi write; ketika paused, perubahan tetap ditolak. **Bila request otomatis mengubah model tanpa izin:** STOP.
11. **Uji** keyboard/responsive 320/768/1440, close/reopen panel, logout dan permission denial. **Ekspektasi:** tetap bisa dioperasikan dan state server terjaga; draft pesan yang belum dikirim tidak hilang saat hanya menutup panel. **Bila gagal:** tangkap satu screenshot sanitized per kondisi.
12. **Tutup** sesi: sign-out, revoke grant, stop tunnel/server via Ctrl+C. **Ekspektasi:** public endpoint tidak lagi bisa mengendalikan proyek. **Bila gagal:** hentikan akses jaringan terlebih dahulu lalu dokumentasikan.

**Penting:** Remote agent melakukan 3 prompt, rendered ACK, owner-only Save BOMC, dan original Editor reopen adalah gate **SE-11**, bukan pengganti acceptance SE-04; jangan klaim alur lengkap dari hasil mock UI.

## E. Kontrak untuk pemegang SE-03 (belum divalidasi live)

BFF Editor mengharapkan kontrak JSON dengan field contract = se04-owner-mcp-v1 dari GET /v1/projects/:projectId/owner/mcp, POST pada /grants, /pause, /ticket, /requests dan GET /requests. Identity OAuth pending harus mengikat exact agentSubject, clientId, projectId, scopes dan pairingCode. Server menegakkan TTL 5 menit/5 percobaan, single writer, revoke/pause dan validasi actor. Tidak ada syarat bagi owner untuk mengimplementasikan backend sendiri. Tidak boleh copy file privat Editor ke repo publik Builder. Client OAuth registrations Claude dan Codex menjadi milik SE-03/operator.

**STOP rules:** issuer/audience mismatch, login salah subject, token ke browser storage, write tanpa grant, wrong/expired code lolos, missed revoke/pause, missing owner consent, CI merah, service belum tersedia, raw secret di URL/log. Jangan memperbaiki melalui bypass/disable security. Kembalikan ke agent pelaksana cloud dengan issue dan bukti.
